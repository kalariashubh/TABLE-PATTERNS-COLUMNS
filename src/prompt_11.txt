Extract the column schedule floor-wise from the drawing.

Return STRICT JSON in this exact format:

{

===========================
EXTRACTION LOGIC
===========================

The drawing is a grid.

Top row → COL. MARK (C1, C2, C2A... C11)
Left column → FLOOR NAME (BASE FLOOR COLUMN, GROUND FLOOR COLUMN, etc.)

Process row by row (floor by floor).
Do NOT merge floors.

---------------------------------------
SIZE EXTRACTION RULES

Examples:

"330 X 1100"
→ width = 330
→ length = 1100

"230 X 1330"
→ width = 230
→ length = 1330

"'L' SHAPE"
→ width = "'L' SHAPE"
→ length = null

---------------------------------------
MIX EXTRACTION

Extract M20 / M25 / M30 exactly.
If blank → null.

---------------------------------------
VERT. REINF → main_bars

Examples:

"16-20 TOR"
→ ["16-20T"]

"10-20 TOR + 6-16 TOR"
→ ["10-20T", "6-16T"]

Rules:
- Replace TOR with T
- Remove extra words
- Split multiple bar types into separate array items

---------------------------------------
RING → links

Examples:

"8 TOR @ 75 C/C"
→ ["8T @ 75 C/C"]

"8 TOR 15 @ 75 + @ 150 + 15 @ 75 C/C"
→ ["8T @ 75 C/C", "8T @ 150 C/C"]

Rules:
- Replace TOR with T
- Extract all spacing values
- Always include C/C
- Do NOT guess missing spacing

---------------------------------------
IMPORTANT

- Do NOT guess values.
- Do NOT copy reinforcement from other floors.
- If a cell is blank, return nulls and empty arrays.
- Only extract visible text.
- Return ONLY valid JSON.

You are an expert RCC structural drawing extractor.

This drawing is a COLUMN SCHEDULE – PATTERN 1.

=====================================================
DRAWING STRUCTURE
=====================================================

The drawing is a GRID:
  Rows    = floor level bands (labeled on the LEFT side)
  Columns = individual column groups (labeled at the BOTTOM in COLUMN MARK row)

LEFT SIDE band label format:
  "[ordinal] FLOOR COLUMN"  e.g. "12 TH FLOOR COLUMN"
  "(MIX : M300)"
  "(SEEL:FE500)"  or  "(STEEL:FE500)"

BOTTOM rows (summary table):
  Size row       → footing plan dimensions per group
  D PD d row     → footing depth range per group
  Short Span row → footing stirrup short span per group
  Long Span row  → footing stirrup long span per group
  COLUMN MARK row → column group labels (e.g. C1,C18 | C8,C9 ...)

=====================================================
CRITICAL — READ THE COLUMN MARK ROW FIRST
=====================================================

Before extracting anything else, scan the COLUMN MARK row at the
very bottom of the drawing from LEFT to RIGHT.

Write down every label you see, exactly as written.
Example labels: C1,C18 | C8,C9 | C8,C17 | C4,C14 | C8 | C7,C18 | C10 | C11,C13 | C18 | C16

⚠️  READ DIGIT BY DIGIT:
    C18 ≠ C8    (18 ≠ 8)
    C11 ≠ C1    (11 ≠ 1)
    C13 ≠ C3    (13 ≠ 3)
    C17 ≠ C7    (17 ≠ 7)
    Only extract groups actually present. Do not invent groups.

=====================================================
STEP 1 — IDENTIFY ALL FLOOR BANDS
=====================================================

Read the band label on the LEFT of each row.
Extract the floor name, mix, and steel grade.
These apply to ALL groups in that band.

Clean the floor name:
  "12 TH FLOOR COLUMN" → "12TH FLOOR"
  "GROUND FLOOR COLUMN" → "GROUND FLOOR"
  "BASEMENT COLUMN" → "BASEMENT"

Extract ALL bands present. Do not assume which ones exist.

=====================================================
STEP 2 — EXTRACT EACH CELL INDEPENDENTLY
=====================================================

⚠️  MOST IMPORTANT RULE:
Every single cell has its OWN values. Read each cell from the drawing.
DO NOT copy values from adjacent cells, even if they look similar.
DO NOT assume all cells in a row are the same.
DO NOT assume all cells in a column are the same.

For each (column group × floor band) intersection:

--- column_no ---
Exact label from the COLUMN MARK row. Uppercase. Comma-separated.
Example: "C1, C18"  or  "C8, C9"  or  "C10"

--- column_name ---
Cleaned floor name. Example: "12TH FLOOR"  or  "GROUND FLOOR"

--- size ---
Two numbers shown on the sides of the rectangular column diagram.
  Number on the SHORT side = width
  Number on the LONG side  = length
  depth = always null for floor columns

Read directly from each individual diagram. Values differ between groups.

--- reinforcement ---
Bar labels written BESIDE the column diagram. Format: "count ф diameter"
Convert: "10 ф 20" → "10-20T",  "4 ф 16" → "4-16T"
A leading "+" means extra bars — strip it: "+4 ф 16" → "4-16T"
Collect ALL labels visible. There are typically 2–3 per cell.
Values differ between groups AND between floors. Read each one fresh.

--- stirrups ---
Label below/beside the diagram. Format: "count ф spacingC/C"
  "16 ф 130C/C" → dia: ["16T"], spacing: ["130 C/C"]
If two lines exist, include both spacings. Values differ per cell.

--- mix ---
From the band label: "(MIX : M250)" → "M250"

--- steel_grade ---
From the band label: "(SEEL:FE500)" → "FE500"

=====================================================
FOOTING TABLE (bottom of drawing)
=====================================================

For each column group, extract one FOOTING record.

  column_name: "FOOTING"
  size: parse the Size row value e.g. "3200 X 4100"
        → width=3200, depth=null, length=4100
        Values differ per group — read each one.
  reinforcement: []
  stirrups: read from Short Span and Long Span rows for that group.
            If both differ, include both spacings.
            Values differ per group.
  mix: from FOOTING DETAILS label if shown, else null
  steel_grade: from FOOTING DETAILS label if shown, else null

=====================================================
SELF-CHECK BEFORE OUTPUT
=====================================================

Before returning JSON, verify:
1. column_no values match EXACTLY what is in the COLUMN MARK row.
   No invented groups (C2, C3, C6 etc. if they are not in that row).
2. Size values are NOT all the same — they vary across groups.
3. Reinforcement lists are NOT all identical — they vary across groups and floors.
4. Total records = (groups in COLUMN MARK row) × (floor bands) + footing records.
